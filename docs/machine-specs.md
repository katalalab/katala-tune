# 機体のスペック比較

Tauri版のサイドバー「スペック比較」から機体を選び、「仕様を収集」を押す。表は横スクロールでき、「差分のみ」と検索で絞り込める。取得元はセルのヒントと「公式情報・取得元」で確認する。JSONコピーには選択中の機体だけを含める。

## 収集方法

Rustの `tune specs-local` は台帳・DBを開かず、その機体の読取結果を `katala_specs.v1` JSONで返す。WindowsはOS内蔵のCIM（PowerShell経由）と、導入済みの場合は `nvidia-smi` を使う。macOSは `system_profiler`、`sysctl`、`pmset` を使う。Pythonや配置した調査スクリプトは使わない。追加ソフトウェアはインストールしない。

`tune specs [機体ID ...]` はローカルまたは既存SSH接続で収集し、私有DBに最新の成功結果と最終試行を保存する。引数省略時は稼働中の非共用機が対象。画面では明示的に選択した機体のみを収集する。台帳の `specs: false`、共用機、退役・一時停止・対象外の機体は収集を拒否する。

遠隔機の `~/.katala-tune/bin/tune`（Windowsは `tune.exe`）にも、この機能を含むRust CLIが必要。見つからなければPATH上のCLIを試す。古いCLIやSSHの失敗は画面で案内し、前回の成功結果を消さない。収集時にはバイナリの自動配布を行わない。通常のアプリ更新で同梱CLIも更新する。

収集は1回限りで、4機体ずつ処理する。遠隔機は1台120秒、WindowsのCIMは100秒、macOSの各providerは22秒、標準出力は2MiBを上限とする。セクションは最大256件。閲覧だけでは再収集せず、24時間以上前の結果と失敗後の前回値には要更新を表示する。

## 表示内容と限界

- 本体・CPU・メモリ・GPU・ストレージ・マザーボード・BIOS/ファームウェア・OS・ディスプレイ・NIC・USB・Thunderbolt/USB4・PCI・オーディオ・取得可能な電源/セキュリティ/仮想化設定。
- メモリは部品番号・スロット・容量・公称転送速度・設定転送速度を分離。容量のバイト数はGiBに換算する。Macの共有メモリを専用VRAMに換算しない。CPUクラスタはOSが報告する名前を表示し、Super/PerformanceをP/Eに推測変換しない。
- WindowsのCIM `AdapterRAM` は専用VRAMとして使用しない。NVIDIAはモデルが一意に照合できる場合のみドライバー報告を採用。同名GPUが複数ある場合、AMD/Intelの専用VRAM、未提供のドライバー/ファームウェア情報は未取得になる。
- セキュアブートの権限不足、OSが公開しないXMP/EXPO、MacのRecoveryポリシーなどは理由を表示する。標準APIに出ない電源ユニット・ケーブル・筐体・冷却部品やBIOSの全設定を推測しない。
- 「OSからの報告なし」「未取得」「未対応」「権限不足」を区別する。OSの仮想デバイスも含むため、デバイス数は物理部品の数ではない。最大クロックや公式仕様だけで性能順位を付けない。

## 公式仕様

`data/specs-catalog.json` に確認日、完全一致する型番、メーカーの出典URL、適用範囲と公表仕様を持つ。初期登録はApple M5 Max、対応する16インチMacBook Pro、Intel Core i9-14900KS、GeForce RTX 4090/5060 Ti。構成違いやボードメーカー固有のクロックを推測しない。未登録型番は「未照合」と明示する。新しい公式仕様はメーカー資料を確認して型番単位で追加する。

OSが報告した構成と公式の選択肢・上限は別に表示する。インターネットへの機体情報送信や自動検索はしない。出典リンクが開けない環境では「URLをコピー」を使う。

## 私有データ

収集にはシリアル番号、UUID、MAC/IPアドレス、SSID、ユーザー名、ファイルパスのフィールドを含めない。Rustが許可したフィールドだけを正規化し、SSHから受信したJSONも再検証する。機体名・台帳・収集した実機JSONはリポジトリに置かない。既存のSQLite `meta` に `specsReport:<id>` / `specsAttempt:<id>` を保存し、旧版のDB構造を変更しない。

## 検証

`cargo test -p tune-core --test specs --locked`、`node --test test/specs.test.js`、`npm run check`。実機では `tune specs-local` と画面からの収集を確認する。Electron互換版ではRust版の利用案内を表示する。
