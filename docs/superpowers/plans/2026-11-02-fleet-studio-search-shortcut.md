# 検索開始キーの復帰後操作

**目的:** focus 復帰後の初回 `/` または `slash` で検索を開始し、ほかの操作キーと確認の安全側判定を維持する。

**範囲:** `NavigationKeyGate::focus_lost` の検索 slot、同 gate と確認の純粋テスト、Fleet Studio README の説明。入力・IME・検索終了処理は変更しない。

**境界:** 検索開始は状態切替と古い確認の失効であり、検索終了時の Enter・Esc や focus 喪失は既存の非同期検索経路へ進む。現行の `search_topology` は固定の未対応結果を返し DB は読まない。文字の長押し・IME・遅延イベント・実 OS の通知順は合成試験だけでは保証しない。

- [ ] `/` と `slash` の初回、held・修飾・解放前の再送、解放後、再度の focus 喪失、他操作キーと古い確認の失効を純粋テストで追加し、修正前の失敗を確認する。
- [ ] 検索 slot だけを変更し、同じ完全指定テストと既存の IME・確認テストを個別に再実行する。
- [ ] README を実装と実測範囲に合わせ、差分を検査して独立レビューを依頼する。実データ・DB・通信・子プロセス・cleanup を伴う試験は行わない。
